Vocabulaire de marque garanti par la feuille de style du design system.

Tailwind ne génère que les classes qu'il rencontre dans les sources analysées. Sans ce
fichier, une couleur de la charte employée par aucun composant — `bg-teal-dark`,
`text-coral` — serait absente du CSS livré : la classe existerait dans le code mais ne
produirait aucun style. Les noms ci-dessous sont donc énumérés pour être compilés, afin
que la palette entière soit réellement disponible à qui compose avec ce design system.
